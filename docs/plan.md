# План разработки трекера цикла (аналог Flo)

Версия от 14 октября 2026. Исходный документ — [`plan.pdf`](plan.pdf); здесь — его текстовая версия для работы.

## Концепция

Сначала сайт, который ставится на телефон как приложение (PWA), потом — App Store и Google Play. Базовые функции работают без регистрации; регистрация по почте открывает синхронизацию между устройствами и режим пары.

Главное отличие от Flo — партнёрский режим как ядро продукта, а не платное дополнение: партнёр видит не только календарь, но и статус дня («как я сегодня», «чего хочу»), а пара ведёт общие заметки. Что именно видит партнёр, решает владелица данных, переключателями.

**Принятые решения:** интерфейс на русском, хостинг в ЕС, весь код пишет ИИ-помощник, заработок — премиум-подписка с бесплатным базовым режимом и бесплатным подключением партнёра.

## Режим пары

Улучшения относительно Flo:

1. **Код одноразовый и короткоживущий**: 6–8 символов, 24 часа, после использования сгорает.
2. **Подтверждение подключения**: владелица видит «Иван хочет подключиться» и нажимает «Разрешить».
3. **Видимость по переключателям**: месячные, прогноз и фаза, фертильные дни, настроение, статус дня, симптомы. По умолчанию — только фаза и прогноз.
4. **Статус дня («желания»)**: энергия, настроение, «нужна забота», «хочу побыть одна», либидо. Партнёр получает уведомление и подсказку по фазе.

Дополнительно: отключение в один клик без объяснений, журнал «кто и когда смотрел», один партнёр одновременно, только с 18 лет.

**Заметки вместо чата**: личные заметки (видит только владелица), общие заметки к дню календаря с реакциями, просьбы-кнопки («принеси грелку», «обними») с отметкой «Сделано».

## Этапы

| Этап | Срок | Что входит | Условие перехода |
|---|---|---|---|
| 0. Подготовка | 1–2 нед. | Ответы на вопросы, макеты 8–10 экранов, черновики политики и соглашения | Есть ответы на главные вопросы |
| 1. MVP: сайт | 4–6 нед. | Онбординг, календарь, журнал, прогноз, гостевой режим, вход по коду, синхронизация, PIN, экспорт и удаление | 5–10 тестировщиц 2 недели без потери данных |
| 2. Режим пары | 3–4 нед. | Одноразовый код, подтверждение, переключатели, статус дня, заметки и просьбы, подсказки | Тесты доступа проходят, 3–5 пар неделю |
| 3. PWA и уведомления | 2–3 нед. | Установка, офлайн, push | Публичный запуск сайта |
| 4. Версия 2 | 6–8 нед. | Зачатие, температура, контрацепция, PDF-отчёт, импорт, советы | Пользуются дольше одного цикла |
| 5. Мобильное приложение | 8–12 нед. | Capacitor или Expo, виджет, публикация в магазинах | — |

## Стек

Next.js + TypeScript + Tailwind; Serwist + Web Push; Supabase (Postgres, Auth, Realtime), регион Франкфурт; IndexedDB для гостевого режима; Resend для писем; Vercel (ЕС); Plausible для аналитики.

Вся логика доступа живёт в правилах базы (Row Level Security), поэтому даже ошибка в интерфейсе не покажет партнёру симптомы или личные заметки.

## Модель данных

См. `supabase/migrations/`. Таблицы плана: `profiles`, `periods`, `day_logs`, `daily_status`, `invite_codes`, `partner_links`, `share_settings`, `shared_notes`, `access_log`.

Отличия реализации от плана:

- `predictions` — последний прогноз, который считает клиент владелицы. Без неё партнёру с включённым «прогнозом», но выключенными «месячными» пришлось бы отдавать историю месячных.
- `invite_attempts` — для лимита попыток ввода кода (5 неудачных в час).
- Вместо представления для партнёра — функция `get_partner_view()`: она же пишет журнал просмотров.

## Алгоритм прогноза (MVP)

Реализован в `src/lib/cycle/predict.ts`.

- Длина цикла = среднее по последним 6 циклам (выбросы < 15 и > 60 дней не учитываются). Пока циклов нет — значение из анкеты, по умолчанию 28.
- Следующие месячные = начало последних + длина цикла; разброс = ± стандартное отклонение, минимум ± 1 день.
- Овуляция = следующие месячные − 14 дней.
- Фертильное окно = от 5 дней до овуляции до 1 дня после неё.

## Приватность и право

Данные о цикле — особая категория по GDPR. До запуска — консультация юриста.

- Серверы в ЕС, действует GDPR. Риск: для граждан России 152-ФЗ требует хранения в РФ — решить с юристом.
- Отдельное явное согласие на обработку данных о здоровье (`profiles.health_data_consent_at`).
- Никаких рекламных SDK рядом с данными о здоровье (урок Flo и FTC, 2021).
- HTTPS, шифрование, RLS, хэши кодов приглашения, лимит попыток.
- Экспорт и удаление аккаунта самостоятельно; Apple требует удаление внутри приложения.
- Возраст: приложение с 13–16 лет по стране ЕС, режим пары — с 18.
- Не медицинское изделие, не метод контрацепции, не заменяет врача.

## Премиум (не в MVP)

Бесплатно: календарь, прогноз, журнал, напоминания, экспорт и удаление, подключение партнёра, статус дня, до 10 общих заметок в месяц, подсказки раз в фазу, графики за последний цикл.

Премиум: безлимитные заметки, ежедневные подсказки, графики за всю историю, PDF-отчёт, режим зачатия, свои симптомы, темы и нейтральная иконка.

Одна подписка на пару, пробный период 7 дней, Stripe на сайте. Запуститься бесплатно, набрать 50–100 пользовательниц и спросить, за что они готовы платить.
